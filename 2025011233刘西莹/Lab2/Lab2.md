## 四、最好情况与最坏情况

### 4.1 最好情况

- [ ] A. `target` 位于数组最后一个位置，比较 `n` 次，`T(n) = n`，时间复杂度为 **`O(n)`**
- [ ] B. 数组中不存在 `target`，比较 `0` 次，`T(n) = 0`，时间复杂度为 **`O(1)`**
- [x] C. `target` 位于数组第一个位置，比较 `1` 次，`T(n) = 1`，时间复杂度为 **`O(1)`**
- [ ] D. `target` 位于数组中间位置，比较 `n²` 次，`T(n) = n²`，时间复杂度为 **`O(n²)`**

### 4.2 最坏情况

- [x] A. 两种情况都需要比较 `n` 次，最坏情况下 `T(n) = n`，时间复杂度为 **`O(n)`**
- [ ] B. 前者比较 `1` 次，后者比较 `n` 次，最坏情况下时间复杂度为 **`O(1)`**
- [ ] C. 两种情况都需要比较 `n²` 次，最坏情况下时间复杂度为 **`O(n²)`**
- [ ] D. 前者比较 `n / 2` 次，后者不需要比较，最坏情况下时间复杂度为 **`O(log n)`**

### 4.3 最好情况和最坏情况不同的原因

- [ ] A. 因为 C 编译器会随机决定循环执行次数，最坏情况代表编译失败
- [x] B. 因为目标值的位置或是否存在会影响比较次数，而最坏情况能够给出算法所需时间的上界保证
- [ ] C. 因为数组长度在程序运行过程中会自动改变，最坏情况代表数组长度为 `0`
- [ ] D. 因为最好情况只出现在 C++ 中，C 语言程序只需要分析最坏情况
